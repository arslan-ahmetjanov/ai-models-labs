## Запуск блокнотов

Нужен Python 3.13 и четыре библиотеки:

```
pip install numpy pandas matplotlib scipy
jupyter notebook notebooks/
```

Блокноты считаются сверху вниз, без пропусков ячеек: часть листингов использует переменные, объявленные выше.

## Отличия от методички

Оба отличия отмечены комментариями в коде:

- **ЛР1** — в первом листинге значения `a` и `b` заданы прямо в ячейке. В методичке они вводятся через `input()`, но в блокноте такой код останавливает выполнение и ждёт клавиатуру.
- **ЛР3** — использовано `np.nan` вместо `np.NaN`. Имя `np.NaN` удалено в NumPy 2.0, и листинг из методички падает с `AttributeError`.

## Известные ограничения

- Листинг 08 в работу не вошёл: файл на Яндекс Диске отдаёт ошибку 500, в PDF текста нет. Для ЛР4 хватает листингов 07 и 09 — это минимум, который требует задание.
- Версии библиотек не зафиксированы: `requirements.txt` нет, окружение собирается вручную. Блокноты собраны в Python 3.13, точные версии NumPy, pandas, Matplotlib и SciPy не указаны.
- Отчёты собраны скриптом, которого в репозитории нет. Правки в `.docx` не переносятся в блокноты и наоборот.
- Нумерация страниц в отчётах рассчитана под Word: в LibreOffice разбивка может сдвинуться.
