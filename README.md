## Запуск

```
python -m pip install -r requirements.txt
python -m jupyter notebook notebooks/
```

Зависимости закреплены в `requirements.txt`: numpy, pandas, matplotlib, scipy и jupyter. Блокноты считаются сверху вниз. Два места отличаются от методички: в ЛР1 значения заданы в ячейке вместо `input()`, в ЛР3 использован `np.nan` вместо удалённого в NumPy 2.0 `np.NaN`.

Генерация случайных данных в ЛР5 и ЛР6 зафиксирована: `np.random.seed(42)` стоит в первой ячейке с данными, повторный прогон даёт те же числа. Сохранённые выводы получены этим прогоном и совпадают с листингами в отчётах; скриншоты в приложениях ЛР5 и ЛР6 сняты до фиксации seed, поэтому на них другие значения.
