## Как запустить блокноты

Нужен Python 3.13 и четыре библиотеки:

```
pip install numpy pandas matplotlib scipy
jupyter notebook notebooks/
```

Блокноты считаются сверху вниз. Два отличия от текста методички отмечены комментариями в коде:

- ЛР1: в первом листинге значения `a` и `b` заданы в ячейке. В методичке они вводятся через `input()`, но в блокноте такой код останавливает выполнение и ждёт клавиатуру.
- ЛР3: использовано `np.nan` вместо `np.NaN`. Имя `np.NaN` удалено в NumPy 2.0, на новых версиях листинг из методички падает с `AttributeError`.
