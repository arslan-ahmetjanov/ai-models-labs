# Лабораторные работы: модели и алгоритмы искусственного интеллекта

Учебные работы по дисциплине «Модели и алгоритмы искусственного интеллекта»: УГНТУ, группа БИЦз-22-01, направление 09.03.03 «Прикладная информатика». Шесть лабораторных — от основ Python и графиков Matplotlib до NumPy, pandas и описательной статистики. Каждая сдана отчётом Word, отчёты собраны из блокнотов, поэтому код и результаты в них совпадают.

## Что внутри

- `reports/` — шесть отчётов `.docx`, по одному на работу.
- `notebooks/` — шесть блокнотов Jupyter с выполненным кодом и сохранёнными выводами; из них собраны отчёты.
- `screenshots/` — экраны выполнения, по одной-две картинки на работу.

## Запуск

```
pip install numpy pandas matplotlib scipy
jupyter notebook notebooks/
```

Блокноты считаются сверху вниз. Два места отличаются от методички: в ЛР1 значения заданы в ячейке вместо `input()`, в ЛР3 использован `np.nan` вместо удалённого в NumPy 2.0 `np.NaN`.
